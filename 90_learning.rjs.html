Lastly

  • Then, we noted we could express a neuron as an object.
class Neuron:

    def __init__(self, weights, bias):
        self.weights = np.array(weights)
        self.bias = bias

    def __repr__(self):
        return "Neuron" + str(self.weights)

    def __mul__(self, other):
        return int(np.sum(self.weights * other) >= self.bias)

What happened?

Examine the results

  • For each prediction, we can determine which row (or column) of the matrix made that prediction.
  • If that prediction is correct, we can “strengthen” the connections.
    • Perhaps increase them by 10% or by .1 or something.
  • If the prediction is incorrect, we can “penalize” the connections.
    • Perhaps decrease them by 10% or by .1 or something.

class Neuron:

    def __init__(self, weights=np.random.rand(9), bias=1):
        self.weights = np.array(weights)
        self.bias = bias

    def __repr__(self):
        return "Neuron" + str(self.weights)

    def __mul__(self, other):
        return int(np.sum(self.weights * other) >= self.bias)
        
    def learn(self, perceived, answer):
        if answer == self * perceived:
            temp = perceived + .5
            temp /= sum(perceived)
            self.weights *= temp
        else:
            delta = self.bias - np.sum(self.weights * perceived)
            each = delta / sum(perceived)
            update = each * np.array(perceived)
            self.weights = self.weights + update
