Setting the Stage

In our lecture, we introduced learning using a .learn method of a neuron.

  1. We started with a neuron that randomly perceived things using random edge weights.
  2. We created a (relatively sophisticated) method to update edge weights.

It took two things:

  1. Some perceived vector of values, corresponding to dots on a die, and…
  2. Whether the neuron should or shouldn’t “activate” in response to that perception.

Here is what we had at the end of class:

import numpy as np

class Neuron:

    def __init__(self, weights=np.random.rand(9), bias=1):
        self.weights = np.array(weights)
        self.bias = bias

    def __repr__(self):
        return "Neuron" + str(self.weights)

    def __mul__(self, other):
        return int(np.sum(self.weights * other) >= self.bias)
        
    def learn(self, perceived, answer):
        if answer == self * perceived:
            temp = perceived + .5
            temp /= sum(perceived)
            self.weights *= temp
        else:
            delta = self.bias - np.sum(self.weights * perceived)
            each = delta / sum(perceived)
            update = each * np.array(perceived)
            self.weights = self.weights + update
  • .learn checks if a the neuron classifies some perception correctly.
    • If so, it does two things:
      • Increases weights on dots that were present
      • Decreases weights that weren’t present
    • Otherwise, it does one thing.
      • Calculates how far off from the bias it was.
        • Regardless of whether it was too high or too low!
      • Divides this “miss” amount among all active weights.
        • This either increases or decreases - whichever should happen.
  • This is probably not the simplest way to write this but it was the first one I got working!

Key-Value Storage

  • We imagine the notion of a print or website dictionary, which stores the following information:
    • Words, and
    • Definitions.
  • The more general form of this recognizes each as keys and values
    • Words are like keys, a brief symbol used to represent some value or collection of values, like the multiple words that form a definition
    • Definitions are like values, they are what a word means, or something that we could substitute for a word to get the same meaning.
best: most good
hot: very warm
long: not short

    • Substitute “hot” for “very warm”
    • Substitute “best” for “most good”
    • Substitute “long” for “not short”
    • And still understand the sentence: “A very warm meal is most good enjoyed after a not short journey.”
    • You can also go the other way, of course.

dictionary = {

### Key-Value Storage

```{.email}

```

### In Colab/Python
